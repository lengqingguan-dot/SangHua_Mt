# 夜出桑华山 文字版

双击项目根目录的 `index.html` 直接进入文字版游戏，无需选择版本，也不会再跳转到子文件夹。默认游戏仍可解压后打开，玩家不需要安装 Node.js 或其他开发工具。

## 项目目录

- `index.html`：文字版完整游戏入口与页面样式。
- `game/`：剧情、战斗、任务、技能、存读档及交互逻辑。
- `game/expeditionContent.js`：六处副本的入口与房间文案、女性敌人设定及肢体表。
- `game/expeditionLimbText.js`：按角色、部位与品质编写的副本肢体介绍。
- `characters/`、`character.js`：人物模板和角色创建。
- `items/`：物品、装备、技能书、料理和场景设施。
- `world/`：地图房间、出口及初始人物与物品配置。
- `assets/`、`夜出桑华山.png`：文字版使用的图片资源。
- `ui.js`：界面显示与输入交互。
- `mod/`、`modLoader.js`：原有 Mod 内容与加载逻辑。
- `save/`：保留的存档目录。
- `tests/`：回归测试。
- `docs/`：世界书、策划案和实施记录；其中的画面版方案为历史资料，不参与当前游戏运行。
- `tmp/`：保留的历史临时资料，不参与游戏运行。

文字版的代码、资源、存档目录和测试已直接放在项目根目录，不再套用“文字版”子目录。画面版目录与其独立入口已移入系统回收站，需要时可以恢复；Git 历史和已有文档均保留。

## 当前文字版内容

保留已有的料理永久加成修复、战斗目标锁定、技能原典学习、同阶研习册升级、副本概率掉落和存档兼容逻辑。

普通监工保持中立，上交100块石块后永久放行，也可主动击杀后使用向上的木梯。新战斗直接自动开始；战斗详情不再显示开始或保存战斗按钮，普通存读档功能保留。

木梯、门、传送阵等传送类场景道具即时切换地点，只显示一行统一颜色的字幕；原有通行条件和坠落伤害保留。战斗技能按钮只显示名称，详细效果在技能栏中查看。

撤走的梯子可在 #24 房间拾取，带到 #23 四号矿道出口后，从背包中使用爬上井口。梯子使用后保留，也可从井口返回矿道。

六处副本的入口卡片与地面物品使用相同尺寸；点击后在详情栏查看背景、普通敌人及首领的实际等级，再选择进入、继续或重置。学院使用原有大石门作为唯一入口。重置可清理未通关或已通关的本轮探索，确认后移除地面战利品，保留已拾取物品。

所有副本默认开放，到达入口即可进入，无需阅读告示、击败外庭守卫或先通关其他副本。城镇广场原有的前三处副本快捷入口也默认可用。旧存档中的解锁标记不再影响进入，不需要重新开局。

“离开副本”只在初始房间，以及已击败首领的首领房间显示；普通房和首领仍存活的房间不能直接离开。击败首领后，即使岔路还有小怪，也可以从首领房保留进度离开。关闭物品等面板后的小地图移动立即执行，不再遗留延迟移动；旧房间或旧世界的小地图点击回调不会作用于新位置。

六处副本共用有固定平面坐标的随机地图：北为纵坐标减一，东为横坐标加一，所有出口都通向相邻且不重叠的房间。每轮生成1间初始房、10～15间普通房、1间首领房，共12～17间；首领距入口10～12步，地图包含岔路。每处只使用一种成年女性小怪和一个女性首领，普通房统一名称与描述，只区分初始、普通、首领三类房间。外庭守卫与封库小怪共用角色设定。

肢体仍为七类十二件，成对部位的评分与尺寸一致；每个部位对应六档不同描写，直接以形态、纹理和魔力痕迹体现品质，不再追加“保存状况”标签。演武不生成尸体，学院首领保留化为结晶的结局。

脚码、罩杯只写在介绍里，不再括号标注在物品名称或肢体选择项上。尺寸作为独立属性参与背包与地面堆叠，不同尺寸不会混为一组。旧档会迁移名称并保留原有尺寸与评分。副本介绍按11种角色和具体部位编写，以手感、肉质与皮肤为核心，只在末尾补一句职业痕迹：头部随评分从平常逐步写到美得不像从矿道里抬出来的东西；躯干重点写臀部与阴部的形状、松紧与触感；脚写鞋靴的磨损和缝补，以及足弓、足底筋肉的软硬；乳房写乳肉的饱满或松软、指压后的回弹与皮面是否有光泽。罩杯另外补一句大小与重量（A 到 E 各不相同），脚码另外补一句大小（34～40 码分别写小巧、偏小、适中、偏大与大得少见），两句都不带品质判断，旧档读入时随部位介绍一起重拼，重复读档不会叠加。封存支矿道的小怪与首领分别改称「女矿工」与「女监工」，旧档中的旧名肢体仍会归并到对应角色。主线与剧情女性（瑟蕾娜、艾琳、华沙、曼德罗拉、玛拉）的三十五件肢体文案已按同样的手感、肉质与断面标准加厚，瑟蕾娜另补齐了头颅、躯干、手、脚的使用互动、榨奶三段与尸体互动九句；她的七道部位料理也补上了正文、步骤与合法辅料。

读旧档时自动修正原副本的空间连接，房间不足时补足十间普通房。原房间ID、当前位置、地面战利品、已清空房间、通关记录和战斗行动预算保留，新增房间不刷怪；旧支援角色归并为该副本小怪。已有肢体也会更新描述，评分、品质和尺寸不重掷。

## 验证

开发者在项目根目录执行以下命令即可运行测试，无需安装额外测试依赖：

```powershell
node --test tests/cooking-bonuses.test.cjs tests/update029.test.cjs
```

当前共101项测试通过，覆盖68个入口脚本；六处副本的210组随机配置逐一检查了平面坐标、方位、房间数、三类房间与两种敌人，并验证新开局和旧存档均无需解锁、出口位置、即时移动和尺寸迁移。另在独立浏览器中验证小地图往返、首领出口、重置，以及同名不同尺寸物品的背包分组和介绍显示。测试不代替完整数值平衡试玩。没有覆盖玩家存档或提交 Git。
