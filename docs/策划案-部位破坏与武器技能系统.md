# 《夜出桑华山》更新策划案：部位破坏与武器技能系统

日期：2026-09-22  
建议版本：0.3.0 首发，0.3.x 扩展  
状态：设计提案；本文不代表功能已经实现。数值均为首轮测试值。  
项目基线：当前 0.2.8 代码及工作区已完成的料理永久加成修复，存档版本为 3。

前置版本衔接（2026-09-22 补充）：[0.2.9 目标锁定与装备技能书获取策划](策划案-0.2.9目标锁定与装备技能书获取.md) 已将目标锁定、武器分类、装备渠道、技能书学习和升级列为先行内容。以下均为尚未实施的提案：0.3.0 复用这些基础，再增加部位破坏；所有玩家主动技能必须通过技能书永久学习，装备只限制能否释放，不再授予或删除技能。本案六个部位技能是后续新增，不替换 0.2.9 的普通伤害技能。

## 1. 更新目标与体验

让战斗从“优先打完敌人的生命值”，扩展为“观察敌人依赖什么部位和武器，再决定如何拆解其战斗能力”。保留自动普通攻击和文字 RPG 的轻量操作，不要求玩家每个回合都点选身体部位。

核心循环：观察敌人预备技能 → 选择目标和部位 → 使用对应武器技 → 积累部位破坏 → 部位失能或脱落 → 敌人属性下降、技能失效 → 地面出现可拾取物 → 战后装备、组装或其他现有物品用途。

玩家应能理解三个直接结果：

- 打掉持武器的手臂，可以使依赖它的武器失效，并阻止特定技能。
- 破坏腿部，可以降低敌人灵巧，封锁冲锋和移动类技能。
- 双臂完整并装备大剑，才可以使用双手大剑技能。背包里有大剑不满足条件。

本次演出以部位状态、战斗日志和掉落提示为主，不增加复杂动作动画。发布形式继续为本地静态游戏包，玩家解压后打开原入口，无新增服务器或运行环境要求。

重要限制：

1. 当前 NPC 多数只有攻击、防御等数值，没有实际装备对象。不能根据“卫兵”或“骑士”的名字推定技能合法，必须补配置。
2. 当前同种 NPC 可以重复使用同一个模板 ID。左右部位状态必须属于一个具体实例，不能写回 `CHARACTER_TEMPLATES`。
3. 当前 `dismemberedLimbs` 记录的是部位类别，无法准确表示“左臂已掉落、右臂仍在”。需要逐部位库存。
4. 当前 `_applyDamageToUnit()` 在生命归零时立即生成尸体。新增部位掉落必须协调死亡顺序，防止致命一击同时生成两份相同部位。
5. 当前技能、屏障结束等路径直接改写或恢复属性。必须经过统一属性计算，否则失去部位的敌人可能在增益结束后恢复完整战力。

## 4. 武器分类

武器的“类别”“伤害类型”“持握方式”分开保存。类别限定已学技能能否使用，伤害类型决定对部位的作用，持握方式决定需要几条可用持握链。技能来源统一为技能书。稀有度继续沿用现有系统，不决定类别。

| 类别 ID | 类别 | 默认持握链数 | 常见伤害标签 | 玩法定位 |
| --- | --- | ---: | --- | --- |
| `dagger` | 短刃 | 1 | `pierce`、`slash` | 低消耗、精确削弱，终结破坏较弱 |
| `sword` | 单手剑 | 1 | `slash`、`pierce` | 均衡部位打击，容易切换目标 |
| `greatsword` | 大剑 | 2 | `slash`、`impact` | 高部位伤害，能使肢体脱落 |
| `cleaver` | 砍刀 | 1 | `slash` | 擅长收尾破坏，整体生命伤害较低 |
| `blunt` | 钝器 | 1 或 2 | `blunt` | 快速打至失能，通常不直接产生肢体掉落 |
| `mining_tool` | 镐与矿具 | 2 | `pierce`、`impact` | 破坏部位护甲，为后续技能创造机会 |
| `polearm` | 长柄武器，后续 | 2 | `pierce`、`slash` | 压制腿部、限制接近 |
| `ranged` | 弓弩，后续 | 按具体武器 | `projectile` | 远程命中依赖持握、装填和弹药 |
| `focus` | 法器，后续 | 按具体武器 | `magic` | 施法媒介；不同法术有不同部位需求 |
| `unarmed` | 徒手、后备动作 | 按具体动作 | `blunt` | 没有可用武器时维持最低战斗能力 |

双持、盾牌和副手槽不在首发范围。单手武器放在当前武器槽，使用主手；主手失能后允许在下次自身行动时换到另一条可用持握链，消耗一次行动，不自动免费换手。

## 5. 身体部位模型

### 5.1 首发界面与内部结构

战斗面板显示六个区域：头部、躯干、左臂、右臂、左腿、右腿。首发破坏技只能选四肢；普通攻击仍打生命值，不默认积累部位伤害。

内部同时维护手和脚，保证兼容现有掉落和魔偶槽位：

```text
躯干
├─ 左臂 → 左手
├─ 右臂 → 右手
├─ 左腿 → 左脚
└─ 右腿 → 右脚
头部：保留，不列入首发可拆除目标
```

“可用持握链”定义为：同侧手臂和手都存在，且都未失能。双臂存在但缺一只手，不能满足双手大剑的要求。当前受伤 NPC 应通过显式身体预设初始化；不可仅凭模板 `count: 1` 猜测左右侧。

### 5.2 部位状态

| 状态 | 判定 | 能力 | 是否生成物品 |
| --- | --- | --- | --- |
| 完好 | 耐久为满值 | 可用 | 否 |
| 受损 | 耐久在 0 与满值之间 | 仍可用；显示耐久，不提前叠加惩罚 | 否 |
| 失能 `disabled` | 耐久为 0，但仍连接 | 不可用，应用属性削弱 | 否 |
| 脱落 `detached` | 支持脱落的技能满足条件 | 不可用；脱落不可重复触发 | 是，每个真实部位一次 |
| 先天缺失 `absent` | 实例初始化即缺少 | 不可用 | 否，不补发掉落 |

钝器将部位耐久打至 0 时进入失能。带 `detach` 能力的技能将部位打至 0 时直接脱落；对已经失能但未脱落的部位，再命中一次带 `detach` 的技能也可使其脱落。

脱落手臂会使同侧手一并离体，立即生成一个手臂物品和一个手物品；腿与脚同理。它们各自消耗一个库存位，彼此关联到同一次掉落事件。首发不额外生成“整条手臂容器”，避免同时存在整件和子件造成复制。

父部位失能只通过依赖关系使子部位暂不可用，不把子部位永久标记为失能。父部位脱落才向子部位传播脱落；已经缺失或已掉落的子部位不再次生成。

### 5.3 首发不增加的规则

不叠加持续失血伤害、永久最大生命下降、伤口感染等系统。生命伤害已经在攻击时结算，部位破坏主要改变能力与战术；避免一次攻击同时扣生命、扣生命上限、再追加持续伤害。

## 6. 部位耐久与伤害数值

### 6.1 部位耐久

以敌人同等级普通单位基础最大生命 `H0` 为基准，排除 Boss 的全身生命倍率和临时屏障：

- 单臂最大耐久：`max(12, ceil(H0 × 0.25 × rankFactor))`。
- 单腿最大耐久：`max(14, ceil(H0 × 0.30 × rankFactor))`。
- `rankFactor`：普通 1.0，精英 1.25，Boss 1.5。
- 破坏韧性 `R`：普通 0、精英 0.10、Boss 0.20；与耐久一起调参，避免两者同时无上限增长。
- 增援不刷新已受损实例；普通治疗不恢复部位耐久。

`encounterRank` 单独配置，不能只看现有 `type === 'boss'`，因为部分强敌当前被标记为 `npc`。

### 6.2 一次命中分别结算生命伤害和部位伤害

生命伤害继续使用现有伤害系统，再乘技能的生命伤害倍率；部位伤害独立计算，以免高防御敌人完全无法破坏。

```text
A = 已计算装备、永久成长、当前有效增益和身体削弱后的攻击
Q = 技能部位倍率
W = 武器部位系数（首发均为 1.0，后续再细分）
P = 目标部位护甲，默认 max(0, floor(当前有效防御 × 0.5))
R = 破坏韧性
B = max(1, floor(A × Q × W × (1 - R) - P有效值))
P有效值 = P × (1 - 本次攻击的部位穿透)
```

生命穿透与部位穿透是两个字段；原有 `armorPenetration` 默认只作用于生命防御，避免大剑·改自动获得两次穿透收益。

部位伤害首发不加入随机浮动。一次攻击只做一次命中判定：闪避则生命与部位伤害都为 0；不再额外掷一次“脱落概率”。技能命中后是否破坏，由耐久和规则决定。

沿用现有灵巧闪避，但物理攻击的最终闪避率统一限制在 0%～60%，以免永久灵巧成长导致无法命中。这个上限同时适用于玩家、敌人和盟友；是本更新需要验证的明确平衡变更。

屏障先吸收生命伤害；部位伤害按未被吸收比例减少：`B实际 = floor(B × 生命穿透屏障比例)`。屏障完全吸收时部位伤害为 0，不能造成失能或脱落；不能通过选择耐久为 0 的部位绕过屏障。

对已经失能部位的脱落转换，要求成功命中、生命伤害未被屏障完全吸收，且理论部位伤害大于 0。

### 6.3 具体算例

测试假人：`H0=60`，当前生命 60，单臂耐久 15，部位护甲 4，普通韧性 0。玩家有效攻击 14，使用部位倍率 1.4 的断部重斩：

`B = floor(14 × 1.4 - 4) = 15`。

命中后右臂耐久降至 0，右臂与尚存在的右手生成掉落。假设本次原普通攻击生命伤害为 11，技能生命倍率 0.55，则生命伤害为 6；目标剩余生命 54，仍可战斗，但失去右侧持握能力。

这是演示用固定条件，不代表所有同等级敌人都应一击掉落。目标体验是普通敌人 1～2 次针对攻击、精英 2～3 次、Boss 2～4 次产生第一次关键破坏；需按装备与等级差实际测试。

## 7. 部位损失与属性削弱

只统计不可用的独立肢链，父子关系不重复计罚。失去左臂和左手，只算一条持握链失效。

| 不可用持握链数 | 物理攻击倍率 | 防御倍率 | 能力变化 |
| --- | ---: | ---: | --- |
| 0 | 1.00 | 1.00 | 正常使用武器 |
| 1 | 0.80 | 0.90 | 双手武器与双手技能失效；单手武器检查具体持握侧 |
| 2 | 0.55 | 0.80 | 无法持武器；保留明确配置的后备动作 |

| 不可用腿链数 | 灵巧倍率 | 能力变化 |
| --- | ---: | --- |
| 0 | 1.00 | 正常行动 |
| 1 | 0.65 | 冲锋、跳跃类技能失效 |
| 2 | 0.25 | 不可跨房间追击或增援；保留原地允许的动作 |

倍率作用于计算结果，不直接修改永久属性；每次只从干净的基础值重算一次。推荐顺序为：等级基础加永久成长 → 加入当前可用装备的平面数值 → 装备百分比 → 身体倍率 → 本次有效临时效果 → 最终取整。临时效果用修饰器表达，不把修改后的数值再当作下一次重算输入。防御仍取非负整数，攻击保留最低 1；灵巧允许为 0。

武器因持握条件不满足时，留在装备栏但标记“无法使用”，攻击计算不再计入其加成。独立的缴械技能未来才能让武器掉落；破坏一条手臂不额外赠送一份武器。

新 NPC 武器需要纳入攻击预算：把一部分原模板攻击拆到装备上，不能直接在旧攻击之上再加整把武器，避免更新后敌人无意间大幅变强。

后备动作按每种 NPC 明确配置，如踢击、肩撞或无需手势的低威力法术。不能以通用“徒手攻击”绕过两条手臂都不可用的限制。无合法进攻动作时执行防御或求援，不重试失效技能。

魔法是否依赖手臂由技能自身声明。无手势法术不自动承受物理攻击削弱；若继续用 `atk` 作为法术数值来源，必须通过“魔法有效攻击”查询绕开物理肢链倍率。

## 8. 技能释放条件与首发技能

### 8.1 统一条件

每个技能可声明：已通过技能书学习、技能等级、武器类别、具体模板白名单、持握链数量、腿链数量、指定部位、当前状态、SP、冷却、行动额度、目标部位状态、目标是否可破坏。玩家侧必须先满足已学习；NPC 按其显式技能配置执行，不要求背包持书。

```json
{
  "id": "greatsword_sever",
  "name": "断部重斩",
  "requirements": {
    "weaponCategories": ["greatsword"],
    "functionalGripChains": 2,
    "functionalLegChains": 1
  },
  "costSp": 8,
  "cooldownRounds": 2,
  "hpMultiplier": 0.55,
  "partMultiplier": 1.4,
  "partOutcome": "detach",
  "targetParts": ["leftArm", "rightArm", "leftLeg", "rightLeg"]
}
```

大剑条件满足时，包括大剑·改在内的该类别武器都可用；只有剧情专属技能才额外配置具体模板白名单。技能是否拥有与条件是否满足是两个判断，不因临时失去手臂就删除已学技能。

面板显示和真正结算前各校验一次。失败不扣 SP、不进冷却、不消耗行动，并给出具体原因，如“需要两条可用持握链，当前 1 条”“当前装备为单手剑”“目标右臂已脱落”。

### 8.2 首发六个武器技

倍率为生命 / 部位，全部属于攻击动作。普通攻击不积累部位破坏。表内数值均为技能 Lv.1；技能原典及同阶研习册沿用 0.2.9 体系，不能装备武器即解锁。

| 技能 | 武器 | 部位/持握条件 | SP / 冷却 | 倍率 | 附加效果 |
| --- | --- | --- | --- | --- | --- |
| 关节刺击 | 短刃 | 1 条持握链；目标四肢 | 3 / 1 回合 | 0.45 / 0.85 | 部位穿透 50%；只造成失能，不直接脱落 |
| 定点斩 | 单手剑 | 1 条持握链；目标四肢 | 4 / 1 回合 | 0.65 / 0.90 | 可直接使部位脱落 |
| 断部斩 | 砍刀 | 1 条持握链；目标四肢 | 4 / 2 回合 | 0.45 / 1.20 | 对失能部位可完成脱落 |
| 震断重击 | 钝器 | 武器规定的持握链；目标四肢 | 5 / 2 回合 | 0.65 / 1.50 | 只造成失能，擅长阻断动作 |
| 破甲凿击 | 镐与矿具 | 2 条持握链；目标四肢 | 4 / 2 回合 | 0.50 / 0.80 | 本次结算后该部位护甲 -50%，持续至本场遭遇结束；不叠层 |
| 断部重斩 | 大剑 | 2 条持握链、至少 1 条腿链 | 8 / 2 回合 | 0.55 / 1.40 | 可直接使部位脱落；主要战术破坏技 |

技能书投放建议：关节刺击、定点斩、断部斩定为优良，分别新增到 D2、D3、D1 的独立部位挑战奖励；震断重击、破甲凿击定为稀有，分别放入 D4、D5 部位挑战；断部重斩定为史诗，放入 D6 部位挑战。以上为 0.3.0 新挑战，不追溯要求玩家重领 0.2.9 首通；完成挑战后该书加入对应副本兑换目录，4 枚该副本凭证可兑换。六技生命倍率按 0.2.9 通用等级成长，部位倍率每级仅比 Lv.1 增加 5%（Lv.5 为 ×1.20），避免高等级跳过部位博弈；SP、冷却与破坏规则不随等级改变。

“横扫压制”作为大剑第二技能，0.3.1 开放：8 SP、3 回合冷却、最多两个敌人，生命倍率各 0.55、部位倍率各 0.50，只造成失能；不同时开放无条件多目标脱落。上表六技是 0.3.0 验收范围。

破甲的遭遇结束指胜利、玩家战败或场景显式重置；逃跑后还有存活敌人时仍是同一遭遇，不刷新护甲与部位耐久。

### 8.3 原技能兼容

- 仇恨：维持精神类增益定位，不要求武器；仍然只在战斗内生效。
- 玩家舍身：保留骑士套装要求，新增大剑类别、双持握链和至少一条腿链要求。现有 20 SP 消耗暂不下调。
- 玩家誓言：本场战斗效果，提示中的“永久”应改为“本场战斗”；它不写入永久加成。
- 莉娅娜的双手攻击：配置真实大剑和双持握链要求，失去一条持握链后停用，改用合法后备动作。
- 施法、祝福、治疗各自配置需求，不能对所有魔法一律施加“双臂完整”限制。
- 先手必杀类技能必须有可见预告和一次有效响应机会后再纳入破坏反制；不能在玩家首次可操作前直接完成即死结算。

初始 10 SP 足够尝试基础技能和一次重斩。普通非首领敌人在首次被破坏时返还攻击者 2 SP，每个敌方实例整个生命周期只触发一次；不对召唤物、盟友或训练假人返还，也不因脱离战斗重置。回合被动回蓝不在首发范围。

## 9. 战斗节奏、打断与敌方 AI

### 9.1 行动预算

当前玩家技能可随时点击且独立于自动普攻，新系统必须增加限制，否则可以连点部位技跳过敌方行动。

- 每名参战者每个全局回合有 1 次攻击行动额度。普攻、武器技、原有伤害技能共享；“舍身”的内部多段攻击仍属于一次动作。
- 玩家可在安全结算边界提前消耗本回合额度发动武器技，随后自动普攻槽跳过，不能再免费普攻。
- 普攻已经结算后，玩家选择的攻击技能排入下回合单个指令槽；执行时重新验证目标、部位、武器与 SP。
- 非伤害增益独立为每回合至多 1 次辅助动作，且受其自身每战次数限制，不创造额外攻击机会。
- 更换装备、换持握侧、战斗中拾取各占用 1 次攻击行动额度，不允许通过快速切装白用多套技能。
- 没有手动指令时继续自动普攻。玩家可选择“自动”“优先破坏持武器臂”“优先腿部”，后两者只在技能合法且有 SP 时执行。

冷却用绝对回合号：第 R 回合使用冷却 2 的技能，下次最早在 R+2；回合中反复开关界面、逃跑重入不能清空冷却。新参战增援从进入后的下一次合法行动获得额度，不补发已错过的回合。

### 9.2 敌方预告和打断

强力部位依赖技能先“准备”，下一次敌方行动才执行，确保期间玩家至少获得一次完整的行动机会。无需打断的基础普攻不预告。

若准备期间所需部位失能、脱落或武器不再可用：立刻取消准备；该敌人的下一次行动用于恢复姿态，不同一行动改为普攻。准备时预留 SP，真正执行才扣除；被取消则释放预留，并按一次失败施放进入冷却。

单纯部位受损不打断。失能造成的取消不掷概率。已经取消的动作不会被下一次破坏重复取消。Boss 每两个自身行动至多承受一次“额外失衡跳过”；冷却期间新部位仍可破坏、相关技能仍会失效，但下次可使用其他合法动作。

打开部位选择默认在当前完整动作结束后暂停战斗推进，确认或取消后恢复。不能暂停到伤害与掉落提交中间。提供关闭战术暂停的选项，但核心反制不依赖毫秒级手速。

### 9.3 行动与属性刷新时机

破坏立即影响后续伤害、技能合法性和是否能追击。本回合已排好的行动序列不重排，灵巧变化从下回合排序开始生效；避免改变索引使单位重复或漏行动。

AI 每次准备和执行均过滤不可用技能。双臂失效但仍可施法的敌人转入法术；双腿失效的弩手可原地攻击但不能增援；没有合法进攻能力则防御，永不循环重试同一失败技能。

## 10. 掉落、尸体和资源规则

### 10.1 活体掉落

部位脱落结算后，同一个原子事件完成：部位状态更新 → 能力重算 → 取消不合法准备技能 → 消耗部位库存 → 创建掉落物 → 刷新日志和场景列表。

地面掉落属于敌人实际所在的战斗房间，不能使用玩家逃跑后的新位置。物品保留 `templateId`、`limbPart`、左右来源、品质和唯一来源标识；战后自动收取为可选功能，首发默认手动拾取。

战斗中可以看到掉落物；拾取消耗一次行动，不能在拾取同一件物品期间又自动普攻。战后处理不消耗行动。

### 10.2 唯一库存规则

以 `entityId + partId + generation` 为每一真实部位的来源键。首发不允许再生，`generation` 固定为 0。

每个部位有且仅有一个去向：仍在单位上、成为地面/背包/组装中的物品，或被消耗。脱落记录不因为物品被拾取、出售、丢弃或消耗而删除。

战斗掉落与尸体拆取共用同一库存。右臂及右手已在战斗中掉落，死亡后尸体只显示左臂、左手等剩余部位。重复按钮、延时回调、读档重播不得生成第二份。

若本次攻击同时使生命和部位归零，先完成唯一一次部位状态与库存提交，再生成反映剩余库存的尸体，最后处理经验和任务；普通死亡不会额外“全身脱落”。

### 10.3 品质与收益

- 在敌方实例首次生成时确定全部可回收部位的评分，战中与战后共享，不能分别随机。
- 同一来源的左右成对评分沿用现有生成器规则；左右身份独立。
- 部位耐久代表战斗连接强度，首发不扣物品评分。玩家主动使用新玩法不会得到比普通战后回收更差的部件。
- 部位破坏不额外增加经验、金币和同一实体的总物品数量；收益是提前拿到物品和削弱对手。
- 不为拆掉每一部位发放逐次奖励，避免玩家拖住失能敌人刷收益。

死亡时化雾、仅掉结晶等特殊敌人配置 `bodyProfile: ethereal` 或专用结构：允许节点失能反制，但不生成普通人形肢体。首发对瑟蕾娜两个形态及学院特殊首领逐一配置，不能让战中掉落绕过原来的死亡奖励规则。

## 11. 玩家成长、魔偶与后续趣味扩展

0.3.0 魔偶维持原有完整组装参战门槛和评分属性，只让新增掉落可正常安装。来源记录中的左右侧用于去重；魔偶安装暂继续按部位类型匹配，避免旧物品没有左右信息而无法使用。

0.3.1 推荐增加三种明确玩法，而非立即扩展所有部位：

1. **武器魔偶**：两个有效臂手链和大剑构成重击型；一条臂手链配短刃形成低消耗型。武器属于魔偶自身装备，不能直接读取玩家武器。
2. **专长继承**：少数部件附带一个数据化专长，例如“部位穿透 +10%”或“准备技能更早显示”。同类专长取最高值，避免简单叠满获得唯一最优解。
3. **控制后收取**：先用钝器使危险部位失能，再用低生命伤害的砍刀完成脱落。与直接大剑重斩形成快攻和稳控两种路线。

玩家自身受伤放在后续独立选项中：默认只产生战斗内失能，离战恢复；若加入永久缺失，必须同时提供可获得的修复、义肢及任务防卡死设计。料理永久加成继续独立保存，部位状态和临时增益绝不能改写它。

## 12. 界面与信息反馈

敌人卡片显示名称、编号、生命状态、准备动作和四肢状态。允许展开查看耐久和具体限制。多个同名敌人显示“卫兵 #1 / #2”，内部使用不同实例 ID。

选择技能后依次选敌人、部位，再显示确认信息：SP、预计部位伤害、目标剩余耐久、成功后关闭哪些能力。生命伤害有随机浮动时显示范围，部位伤害显示确定值；不要把闪避后的失败当作确定命中。

示例提示：

> 断部重斩 → 卫兵 #2 右臂，预计部位伤害 15，耐久 15/15。命中后可破坏；双手重击将失效。消耗 8 SP 和本回合攻击行动。

成功日志只输出一组摘要：

> 卫兵 #2 的右臂脱落，双手重击被取消。右臂与右手落在地面。攻击下降，下一次行动恢复姿态。

错误原因就地显示，不仅把按钮变灰。地面列表突出本回合新增物品，可按部位和来源筛选。首发用现有文字和图标完成，不要求新美术资源。

## 13. 内容投放与三场教学战

| 场景 | 敌人配置 | 玩家学习目标 | 通关替代方案 |
| --- | --- | --- | --- |
| 矿区教学 | 普通近战敌人，臂部耐久较低，无保护 | 使用破甲凿击或定点斩，理解耐久 | 普攻仍可胜利 |
| 卫兵挑战 | 明确持双手武器，准备重击一整轮 | 破坏任一持握链关闭双手技能 | 防御、消耗品或较高等级硬打 |
| 精英追击者 | 低腿甲、高臂甲、准备冲锋 | 选择腿部封锁冲锋和追击 | 击败或合法逃离 |

教程首轮免费提供一次可重置训练，不发放可出售或装配的真实掉落。NPC 不能强制要求玩家使用已经缺失、拿不到的特定武器才能推进主线。

关键剧情检测优先读取语义事件 `npc_defeated`、`part_disabled`、`part_detached`。身体受伤不自动视为 NPC 死亡，主线对话和击败条件不能混用。

### 14.1 建议模块

| `game/bodySystem.js` | 身体预设、实例部位、父子依赖、耐久与状态变化 |

### 14.3 内容编辑字段

未来 Excel/JSON 编辑工具可使用下列逻辑表，首发可以先用 JS 数据对象承载：

- 武器：ID、类别、持握链数、伤害标签；不配置授予技能。
- 身体预设：预设 ID、部位 ID、父部位、耐久倍率、初始缺失、掉落映射。
- 技能：ID、武器条件、部位条件、SP、冷却、倍率、破坏结果。
- NPC 战斗配置：模板 ID、身体预设、主手、装备、技能、后备动作、遭遇等级、韧性。

复杂判断保留为程序规则，表里存参数与枚举。使用稳定 ID 引用，不从中文名称解析部位或武器类型。

### 14.4 统一结算接口

`canUseSkill(actor, skill, target)` 返回 `{ ok, reasons }`；`resolveCombatAction(command)` 产生一次可提交结果。

顺序固定为：验证身份与条件 → 扣除本次行动资源 → 命中 → 屏障 → 生命与部位变化 → 掉落去重 → 属性/技能变化 → 死亡与尸体 → 经验任务 → 界面。

一个指令携带 `actionId` 和遭遇 ID，重复提交直接返回已处理结果。保存、读档、切房间和退出主菜单时注销旧遭遇计时器；旧回调不能操作新遭遇的单位。目标已死亡或已脱落时拒绝指令，不默认改打另一名敌人。

## 15. 存档与旧版本迁移

版本规划调整为：0.2.9 先以 `v3 → v4` 保存技能学习、目标锁定及副本进度，0.3.0 再以 `v4 → v5` 加入身体库存与部位状态。此前 v2 → v3 的料理兼容仍先执行，不能跳过；本案不得覆盖 0.2.9 的技能等级和副本奖励记录。

必须保存：单位实例 ID、房间归属、身体状态、耐久、部位库存、动态物品来源、已发放奖励、武器实例、技能冷却、遭遇轮次、行动额度与未完成准备动作。评分不能在读档时重抽。

玩家 SP、每战技能使用标记和临时效果属于遭遇状态。当前开始战斗会回满 SP、恢复后台战斗会重置部分技能标记；实施时必须区分“新遭遇”和“同一遭遇恢复”，后者不回满资源、不重置已用技能，防止逃跑重入刷连续部位技。保存使用的冷却时钟与遭遇轮次必须相同，后台推进时也同步更新。

当前 0.2.8 前台战斗未完整写入存档，0.2.9 策划已要求补齐遭遇快照；0.3.0 应在其上扩展身体字段并回归，不能只加身体字段就宣布支持战中存档。规则保持为：保存请求等当前动作原子结算结束后执行，记录完整遭遇快照；读档清理全部旧计时器，恢复快照并停在“继续战斗”状态，玩家点击后从下一合法动作推进，不重复已经完成的伤害或掉落。文件选择器打开期间暂停游戏模拟。

离线期间不推进战斗；后台战斗仍可简化 AI，但部位、属性、技能可用性、掉落和死亡必须复用相同领域规则。所有实体状态只有一份权威数据，前台快照和后台记录引用同一实例，不能各复制一份可独立发放掉落的身体。

旧档迁移规则：

1. 房间中重复模板 ID 按持久化实例表拆分；首次迁移分配唯一 ID 并随新档保存，以后不得按房间位置重新生成。
2. 已知受伤角色用显式预设，其他存活普通人形默认完整；旧版没有记录的历史战斗伤势不凭空推断。
3. 已有尸体的 `dismemberedLimbs` 只能证明某类别处理过，无法准确恢复左右。保守标记该类别全部已领取，优先避免复制；可能少恢复的旧部件不能自动补发。
4. 已有背包/地面/魔偶物品没有来源键时，标为旧物品并分配物品 UUID；不反向猜测归属哪个当前存活 NPC。
5. 尸体旧随机评分尽量沿用 `generatedLimbs`，不因打开新界面重新生成。
6. 特殊 NPC 的不同剧情形态使用显式身份映射，决定身体伤势应继承还是新实体；不能从名字相同推断为同一身体。
7. 新游戏重置实例表与身体库存，继续从默认完整玩家开始。

## 16. 平衡、保护与反滥用

- 同等级正常装备下，普通战斗平均操作量目标不超过额外 2～3 次有效点击；可使用记忆部位快捷键减少重复选取。
- 首发不新增根据玩家操作动态提高的隐藏部位耐久。Boss 保护和特殊结构明确显示。
- 关键 Boss 可以有阶段护甲，先破甲后破坏；首轮至少存在一个可理解的反制目标，不四肢全免疫。
- 对剧情保护目标可禁用脱落、保留失能控制，界面显示“剧情保护：只能失能”；不能让玩家花完资源才知道无效。
- 同一部位无重复掉落，逃跑重入不重置品质、返蓝、耐久或冷却。
- 再生不在首发范围。若后续加入，再生部位必须标记不可再次产出可交易物品，或设置明确的有限再生库存。
- 控制路线以低生命伤害换取削弱和反制，纯输出路线以更快击败为优势，不能让部位技能同时在伤害、资源和战利品上全面占优。
- 单机读回较早存档重试属于允许的玩家行为；当前存档内部必须一致，不承诺跨不同存档的全局防刷。

本地平衡测试记录回合数、首次破坏发生回合、SP 剩余、部位技使用占比、纯普攻通关率。只在开发测试输出，不新增联网统计。

## 17. 开发顺序与工作量估计

以下为熟悉当前项目的一名开发者的净开发估算，包含基础回归，不含新增大型美术或地图制作。不要把各阶段直接理解为固定交付日期。

| 阶段 | 内容 | 预计 | 完成标准 |
| --- | --- | --- | --- |
| A 数据基础 | 实例 ID、武器分类、身体预设、属性推导 | 4～6 天 | 两个同模板敌人状态互不影响；原有伤害和料理测试通过 |
| B 核心闭环 | 单敌选臂、一个重斩、失能/脱落、即时掉落、尸体去重 | 4～6 天 | 手动验证完整的一战两次回收流程，不重复物品 |
| C 战术层 | 六技能、统一需求、行动预算、预告打断、AI 后备行为 | 5～8 天 | 双臂与大剑条件双向生效；自动模式可完整战斗 |
| D 持久化 | 逃跑、增援、后台战斗、前台快照、旧档迁移 | 5～8 天 | 多房间、多同名单位、任意安全存档点恢复一致 |

合计约 22～35 个工作日；核心难点是实例身份、战斗时序和存档一致性，综合难度约 7/10。仅做“一个敌人、一把大剑、一次破坏”的技术原型约 3～5 天，但不能替代正式版本的掉落和读档验收。

## 18. 验收清单

### 功能与数值

- [ ] 7 件现有武器全部正确分类；动态改造武器通过模板映射识别为大剑。
- [ ] 双持握链加已装备大剑可释放重斩；缺手、缺臂、错误武器、未装备均正确阻止。
- [ ] 只伤而未失能时不提前削弱；耐久归零后按失能/脱落规则生效。
- [ ] 失去一臂只罚一次，不因附属手同时不可用重复惩罚。
- [ ] 钝器不会凭空掉落完整肢体；失能后切换砍刀可以完成一次脱落。
- [ ] 完全吸收攻击的屏障也阻止部位破坏；命中失败不扣部位耐久。
- [ ] 生命与部位同一击归零，只产生一次对应掉落及剩余尸体。
- [ ] 增益、屏障结束、治疗、升级和读档不会抹掉身体削弱或料理永久加成。

### 战斗流程

- [ ] 连点、双击、切换面板不能额外获得攻击；释放失败不消耗资源。
- [ ] 选取目标死亡或目标部位提前脱落时，指令安全失败而不改打其他目标。
- [ ] 强力技能预告后玩家有至少一次行动机会；打断不产生同一槽位免费反击。
- [ ] 破坏腿部只影响后续回合排序，不让本回合重复行动。
- [ ] 没有可用技能的敌人可执行后备动作；没有合法进攻动作时防御，不死循环。
- [ ] 两个同模板 NPC、来自其他房间的增援有独立身体；掉落归属正确房间。
- [ ] 逃跑后返回、后台盟友击破、战斗转前台都保留部位状态和返蓝标记。

### 掉落与存档

- [ ] 战中已掉右臂与右手，战后尸体不能再次取出，左侧仍可取出。
- [ ] 地面拾取、丢弃、装到魔偶、出售及其他物品消耗，不会重新开放源部位库存。
- [ ] 读档不重抽品质、不重新发掉落、不重播已完成伤害。
- [ ] v2、v3、v4 旧档及旧尸体都可加载；0.2.9 技能等级、目标和副本进度不丢失，料理修复已有 15 项回归继续通过。
- [ ] 战败后读取破坏前和破坏后两种存档，分别恢复对应时点的状态。
- [ ] 前台存档等待动作提交；文件选择器期间暂停；加载后旧计时器全部失效。
- [ ] 解压后本地打开可运行，不请求在线依赖；未使用新玩法的玩家仍能自动战斗。

## 19. 面向玩家的更新说明草案

新增武器分类与部位破坏：不同武器拥有专属招式，你可以瞄准敌人的手臂或腿部，削弱战力、打断准备中的攻击，并让被击落的部位成为地面物品。双手技能现在需要对应的部位和武器条件；失去支撑后，敌人会改变战术。战斗仍支持自动普通攻击，喜欢策略的玩家可以主动选择破坏目标。旧存档提供兼容迁移。

发布前仅保留已完成并验收的条目，0.3.x 的魔偶武器和玩家受伤模式不写入 0.3.0 已上线内容。
